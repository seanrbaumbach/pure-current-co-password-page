# Pure Current Co. — Coming Soon / Password Page

A custom Shopify Liquid section and template built for **Pure Current Co.**, a beach-lifestyle brand launching in January 2027, where 10% of every purchase funds ocean conservation.

This is a freelance case-study project: a coming-soon/password page designed to build early-access anticipation ahead of launch, with an email capture form so visitors can sign up for updates before the store goes live.

## What's in this repo

- `sections/main-password.liquid` — the custom Shopify section powering the password page: responsive logo handling, the native storefront password-entry drawer, brand messaging, and an embedded newsletter signup form wired to Shopify's customer/newsletter tagging.
- `templates/password.json` — the template configuration wiring the section into Shopify's password template, including a rich-text banner ("We're launching January 2027") and references to the brand's logo and background imagery.

## Highlights

- Built entirely in Shopify's native Liquid + JSON template system (Online Store 2.0 architecture), no third-party apps required for the password-page experience.
- Brand-forward copy ("Beach essentials, thoughtfully made.") paired with a clear conservation message baked directly into the page.
- Newsletter signup integrated with Shopify's built-in customer form and tagging, so early subscribers are segmented automatically ahead of launch.
- Fully theme-editor-configurable: logo, background image, and heading copy are all exposed as section settings so the client can adjust them without touching code.

## About this project

Built as part of freelance theme development work for Pure Current Co. This repo isolates the password-page section and template as a standalone, reviewable case study.
